# Upstream drafts

Text for issues and pull requests we want to offer [calagopus/panel](https://github.com/calagopus/panel), one file each. Agents write drafts here and never post them.

Calagopus [does not accept code written by AI or LLM tools](https://github.com/calagopus/panel/blob/main/CONTRIBUTING.md#ai--llm-usage), even small amounts; generated descriptions are fine. So a draft here is only the proposal. If upstream wants the change, a person writes the code themselves, runs `cargo fmt`, `cargo clippy`, `pnpm fmt` and `pnpm lint:fix`, and opens the pull request. Features go to an issue or their Discord first; small fixes can go straight to a pull request.
